# Canonical cut

One file is the source of truth for this recording. Every asset built from it is logged in
`publish-log.md` with the `edit_id@revision` it came from, so when this file changes,
`stale-check` can tell you what now points at the wrong version.

Change `edit_id` or `revision` only on purpose, and add a row to History when you do.
